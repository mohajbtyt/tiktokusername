فاحص يوزرات TikTok — نموذج بخادم محلي

مهم:
- لا توجد واجهة رسمية عامة مخصصة لفحص توفر اسم المستخدم.
- هذا النموذج يقرأ صفحة الملف العامة، وهو غير رسمي وقد يتوقف بسبب تغييرات الموقع أو الحماية.
- الحالات: غير متاح (ظهرت بيانات حساب)، متاح محتمل (ظهر رمز عدم وجود مستخدم معروف)، تعذّر التحقق (أي استجابة غير حاسمة).
- «متاح محتمل» ليس ضمانًا؛ الحسم النهائي يكون من داخل تيك توك عند محاولة اختيار الاسم.
- لا يوجد تجاوز للحظر أو استخدام بروكسيات؛ الطلبات متباعدة لتقليل الضغط.

التشغيل على كمبيوتر:
1. ثبّت Python 3.10 أو أحدث.
2. افتح الطرفية داخل هذا المجلد.
3. نفّذ: python server.py
4. افتح http://127.0.0.1:8000

على هاتف Android:
تشغيل خادم Python المحلي يحتاج بيئة Python محلية، أو نشر الخادم على استضافة موثوقة. ملف HTML وحده لا يستطيع عادةً فحص TikTok مباشرةً بسبب قيود المتصفح (CORS) ولأن ذلك لا يوفّر تحققًا موثوقًا.

هذا مثال تعليمي غير رسمي؛ تحقّق من شروط تيك توك قبل تشغيله على نطاق واسع.


نشر تجريبي على الإنترنت عبر Render:
1. ارفع هذه الملفات إلى مستودع GitHub جديد (مستودع عام أو خاص).
2. أنشئ حسابًا على Render، ثم اختر New > Blueprint، واربط مستودع GitHub.
3. سيقرأ Render ملف render.yaml ويجهز خدمة الويب.
4. بعد اكتمال النشر، افتح الرابط الذي يمنحك إياه Render من الهاتف.

ملاحظات:
- هذا المشروع غير رسمي ولا يضمن اكتشاف التوفر؛ تيك توك قد يمنع الطلبات أو يغير بنية الصفحة.
- الخدمة المجانية قد تنام عند عدم الاستخدام، وقد يتغير زمن الاستجابة.
- لا تضف مفاتيح أو كلمات مرور إلى ملفات المشروع.
- لا تستخدم الخدمة لتجاوز حظر تيك توك أو لإرسال طلبات كثيفة.
- لم يتم نشر الموقع نيابةً عنك؛ يلزم ربط حساباتك والموافقة على النشر من طرفك.
